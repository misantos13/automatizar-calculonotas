Projeto desenvolvido para atividade de **Desenvolvimento de Sistemas I - Agenda 10**. Tendo a proposta de fazer a **Automação de Notas Escolares**  recolhendo informações como **Nome** e **Notas Bimestrais** do usuário.

---

# Objetivo do Programa 📝

Esse projeto tem como objetivo recolher a **quantidade de alunos na turma**, seus **nomes** e **notas bimestrais** e apresentar a **média das notas**, assim como a situação do aluno (**aprovado** ou **reprovado**), e a quantidade de **aprovados e reprovados na turma**.

**Condições:**

* Coletar **Nome** e **Nota de cada bimestre**.
* Apresentar se o aluno foi **Aprovado** ou **Reprovado**.
* Apresentar o **total de aprovados e reprovados** na turma.

---

* Publicação do código-fonte através do Git e GitHub

# Como Utilizar? 👨‍💻

**Pré-requisitos**

→ Ter o Python 3 instalado no computador.

Para verificar se o Python está instalado, execute no terminal:

```bash
python --version
```
---

**Executando o projeto**

→ Clone este repositório:

```bash
git clone https://github.com/misantos13/automatizar-calculonotas.git
```

→ Entre na pasta do projeto

→ Execute o programa `app.py`

---
# O que fazer no Programa 🤷‍♂️

→ Inicie o programa.

→ Informe a **quantidade de alunos na turma**

→ Informe o **nome** e **nota bimestral**. 

→ Ao final da coleta de dados, o programa irá informar se o aluno foi **aprovado** ou **reprovado** e ao fim a **quantidade total de aprovados e reprovados na turma**.
